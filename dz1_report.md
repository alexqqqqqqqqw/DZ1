# Сравнение агентов для «Нормы»

## Задача и требования

Нужен один репозиторий: мобильный веб, PostgreSQL, регистрация, заказы, тестовая оплата, тесты. Данные пользователей и пароли остаются на машине разработчика. Бюджет учебный: платный облачный билдер на каждый прогон не заложен. Доступа к файлам проекта и к локальной базе облачному агенту без выгрузки репозитория нет.

Требования, по которым сравнивались инструменты:

- контекст всего репозитория, а не одного файла
- скорость черновика экрана
- качество кода, который проходит типчек и тесты
- стоимость на учебном объёме
- где оказываются схема базы и `.env.local`
- насколько инструмент встаёт в уже открытый репозиторий

Шкала 1–5. 5 — лучше для этой задачи.

## Сравнительная таблица

| Критерий | Bolt.new | Lovable | Cursor | GitHub Copilot | Cline |
| --- | --- | --- | --- | --- | --- |
| Класс | Cloud | Cloud | IDE | IDE | IDE / CLI |
| Контекст проекта | 2 | 2 | 5 | 3 | 4 |
| Скорость черновика | 5 | 5 | 4 | 3 | 4 |
| Качество кода под тесты и SQL | 2 | 2 | 4 | 3 | 3 |
| Стоимость на этот объём | 2 | 2 | 4 | 3 | 4 |
| Данные и секреты | 2 | 2 | 5 | 4 | 4 |
| Встройка в текущий процесс | 2 | 2 | 5 | 4 | 3 |
| Сумма | 15 | 15 | 27 | 20 | 22 |

Пояснения к оценкам:

- Bolt.new и Lovable быстро собирают визуальный каркас и сразу показывают его в браузере. Для «Нормы» этого мало: заказы, RLS и cookie живут рядом со схемой. Выгрузка репозитория в чужой рантайм каждый прогон расходится с требованием держать пароль базы локально. Контекст обрывается на файлах, которые облако само сгенерировало.
- GitHub Copilot хорошо дописывает функцию в открытом файле. Ему хуже даётся связка экрана, миграции и теста в одном проходе, поэтому контекст оценён на 3.
- Cline держит репозиторий локально и умеет длинный план. На этой машине основной цикл уже был в Cursor, отдельный CLI-агент добавил бы второй контур без выигрыша по секретам.
- Cursor видит дерево, тесты и локальный PostgreSQL в одной сессии. Черновик экрана чуть медленнее облачного конструктора, зато правка сразу попадает в тот же репозиторий, где лежат `db/001_schema.sql` и `src/lib/domain.ts`.

## Выбор

Для этой задачи взят Cursor.

Решающие факторы:

1. Схема, API и экран правятся в одном дереве, и тест запускается здесь же.
2. `DATABASE_URL` и `JWT_SECRET` остаются в `.env.local` и не нужны облачному конструктору.
3. Учебный объём закрывается подпиской IDE, без отдельного кредита на каждый визуальный прогон.

Почему не остальные:

- Bolt.new и Lovable быстрее рисуют первый экран, но плохо держат PostgreSQL с RLS и не оставляют секреты только на локальной машине.
- GitHub Copilot уместен для точечной правки, но не как единственный агент на путь от миграции до оплаты.
- Cline близок по локальности, но второй агент поверх уже открытого Cursor не нужен для одного MVP.

## Настройка

Cursor уже был средой этой сессии. Отдельно ставились Node.js-зависимости проекта, PostgreSQL 16 и роль `norma_app`. MCP для внешнего сервиса не подключался: каталог, заказы и оплата живут в этом репозитории. Проверочный проект — само приложение, команда `npm run dev` на порту 38471.

## Практический прогон

Задача прогона: карточка рациона и правило даты.

Промпты по ходу работы:

1. «Вынеси дату доставки в чистую функцию: календарный день Москвы плюс 2, не 48 часов».
2. «Карточка набора получает цену в копейках. Неделю не умножай на 7».
3. «Рядом с каталогом сделай состояние сети с кнопкой Повторить, пустой список заказов ошибкой не считай».

Итерации: первая версия карточки считала неделю как семь дней (это зафиксировано в `testing.md` как ответ до правил). После правил цена приходит из каталога. Третья итерация добавила тест на 5 490 ₽ и тест кнопки «Повторить».

Сложность: `usePathname` в оболочке при Cache Components требовал границы `Suspense`, иначе prerender ругался на клиентский хук. Оболочка обёрнута в `Suspense` в `src/app/(shop)/layout.tsx`.

## Выводы

Облачный агент годится, когда результат — кликабельный макет без своей базы. Здесь нужны миграция, RLS и тесты, поэтому локальный IDE-агент точнее. Copilot имеет смысл оставить вторым инструментом на правку одной функции. Cline — запасной локальный агент, если сессия Cursor недоступна.

Доказательство прогона — репозиторий: `npm test` и приложение на порту 38471. Скриншоты экранов лежат в `ui_concepts/`.
