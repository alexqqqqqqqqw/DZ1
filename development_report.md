# Отчёт о разработке интерфейса

## Процесс

Интерфейс собран по пути из `user_journey.md` и требованиям из `technical_specification.md`. Стек: Next.js 16, TypeScript, Tailwind, shadcn/ui. Экраны клиентские, данные приходят из `/api`, чтобы сессия и база не попадали в статический каркас страницы.

Порядок работ:

1. Чистые правила даты, телефона и карты.
2. Карточки, пустое состояние и ошибка с повтором.
3. Онбординг, каталог, меню, оформление, вход, оплата, заказ.
4. Три статических концепции в `/concepts`.
5. Прогон в браузере по пути от первого экрана до статуса «Доставлен».

## Промпты и что из них вышло

| Промпт | Результат |
| --- | --- |
| Календарный день Москвы плюс 2 | `earliestDeliveryDate`, тест на 21:30 UTC |
| Цена набора не пересчитывается | `PlanCard` и заказ на 549000 копеек |

Шаблон генерации компонента и шаблон рефакторинга взяты из `prompt_templates.md`. Цепочка из трёх шагов записана в `prompt_methodology.md`.

## Отладка

Симптом: в логе разработки `usePathname()` блокировал prerender оболочки.
Причина: Cache Components считает pathname данными запроса. Хук стоял в layout без `Suspense`.
Правка: `ShopLayout` рендерит оболочку внутри `Suspense`.
Проверка: повторные `GET /`, `/rations`, `/checkout` отвечают 200 без нового digest `CLIENT_HOOK_DYNAMIC`.

Симптом на скриншоте первого экрана: вместо цены был запасной текст.
Причина: кадр снялся до ответа `/api/diets`, а запасной текст выглядел как готовое состояние.
Правка: пока запрос идёт, на экране «Считаем минимальную цену дня.» После ответа — «Дневной набор от …».

Адаптив проверялся на ширине 390 и 1280. Нижняя навигация видна только на узком экране, на широком те же три пункта стоят в шапке. Концепция «Смена» специально оставлена таблицей: на 390 она тесная, это записано как минус, в продукт она не пошла.

## Тесты

`npm test` запускает 13 проверок: правила даты и карты, карточка и кнопка «Повторить», интеграция заказа с RLS и оплатой. Команда должна завершаться без падений до сдачи.

## Что сработало

Короткие промпты на одно правило (дата, цена, код ошибки) давали код, который сразу покрывался тестом. Длинный промпт «сделай весь путь» без разреза на домен, API и экран смешивал пересчёт цены с вёрсткой. Этот смешение как раз показано в `testing.md`.
