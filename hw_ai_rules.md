# Шаг 1. Проект и стек

Проект новый: «Норма», заказ готового рациона на день или неделю.

Стек:

- TypeScript, React 19, Next.js 16 (App Router, Cache Components)
- Tailwind CSS 4 и shadcn/ui (base-nova)
- PostgreSQL 16, доступ через `pg`, схемы в `db/001_schema.sql`
- Проверка: Vitest и Testing Library
- Сессия: JWT в httpOnly-cookie, пароль bcrypt

Требования к коду, которые легли в правила:

- строгий TypeScript, без `any`
- русские тексты интерфейса и английские имена в коде
- деньги в копейках
- один формат ошибки API
- SQL только параметрами
- заказы закрыты row level security
- полный номер карты и пароль не попадают в журнал
- у списков есть загрузка, пустое состояние и ошибка с повтором
